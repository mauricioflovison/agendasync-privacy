Política de Privacidade
Última atualização: 10 de junho de 2026

1. Introdução
A AgendaSync foi desenvolvida para permitir que os usuários gerenciem seus eventos do Google Calendar e suas tarefas do Google Tasks diretamente pelo navegador.

Esta Política de Privacidade descreve quais informações são acessadas pela extensão e como elas são utilizadas.

2. Informações acessadas
A AgendaSync pode acessar, mediante autorização explícita do usuário:

Eventos do Google Calendar
Calendários da conta Google
Tarefas do Google Tasks
Dados de autenticação via OAuth

3. Como as informações são utilizadas
As informações acessadas são utilizadas exclusivamente para:

Exibir, criar, editar e excluir eventos do calendário
Exibir, criar, editar e concluir tarefas
Enviar notificações relacionadas às funcionalidades da extensão
Manter o usuário autenticado durante o uso da extensão

4. Compartilhamento de dados
Não vende dados dos usuários
Não compartilha informações pessoais com terceiros
Não utiliza os dados para publicidade
Não utiliza os dados para criação de perfis de marketing

5. Armazenamento de dados
A AgendaSync pode armazenar localmente configurações da extensão utilizando o armazenamento fornecido pelo navegador Chrome.

Nenhum dado do Google Calendar ou Google Tasks é armazenado permanentemente em servidores próprios.

6. Segurança
A AgendaSync utiliza os mecanismos oficiais de autenticação do Google (OAuth 2.0) para acesso às informações autorizadas pelo usuário.

O acesso aos dados ocorre exclusivamente através das APIs oficiais do Google.

7. Permissões utilizadas
Todas as permissões são usadas exclusivamente para fornecer as funcionalidades da AgendaSync:

Google Calendar API
Google Tasks API
Armazenamento local do navegador
Notificações do navegador

8. Revogação de acesso
O usuário pode revogar o acesso da AgendaSync à sua conta Google a qualquer momento através das configurações de segurança da Conta Google.

9. Alterações nesta política
Esta Política de Privacidade poderá ser atualizada periodicamente para refletir melhorias e alterações na extensão.

A data da última atualização será sempre informada no início deste documento.
